## 멘토에게
- 인증/인가 관련 라우터, 컨트롤러, 서비스, 미들웨어, 유틸함수는 `./src/auth` 디렉토리로 모듈화하여 분리하였습니다.
- `authController.js`에 다음과 같은 미션 외 기능을 추가 구현했습니다:
  - `refresh()`: 심화 요구사항인 Refresh Token 기반 인증 기능을 구현하면서, Sliding Session 방식을 적용하였습니다.
  - `logout()`: Refresh Token 기반 인증에서 보안을 고려해 로그아웃 기능을 추가하였고, 이는 과제 요구사항에는 없지만 실무적인 관점에서 필요하다고 판단했습니다.
  - 두 함수 모두 `jsDoc`을 작성하여 의도와 사용법을 기재했습니다.
- `likeService.js`의 `likeTarget()`, `unlikeTarget()`, `isTargetLiked()` 좋아요 관련 함수는 `product`와 `article` 간의 공통 구조를 동적 키 맵 기반 추상화로 처리하였습니다.
  - `type` 파라미터를 활용해 분기 없이 동적으로 키를 설정하며, 추후 다른 리소스(comment 등) 확장에도 대응 가능하도록 설계했습니다.
  - 해당 로직에도 `jsDoc`을 작성하여 의도와 사용법을 기재했습니다.
- `authorizeMiddleware.js`의 인가 검증 로직은 `authorize(type)`으로 추상화해, 각 리소스의 소유자만 수정/삭제 가능하도록 통일된 구조로 구현했습니다. 코드 중복을 줄이고 확장성을 고려하여 설계했습니다.
